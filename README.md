# Project Builder — Homebrew Tap

Official Homebrew tap for the **Project Builder CLI** (`builder`), a
schematic-driven CLI for initialising, scaffolding, and maintaining software
projects.

## Install

```sh
brew install Project-Builder-Schematics/tap/pbuilder
```

This installs the `builder` binary.

## Runtime requirement

`builder` executes schematics through a [Bun](https://bun.sh) sidecar. Install
Bun if you don't have it:

```sh
brew install oven-sh/bun/bun
```

## Upgrade

```sh
brew upgrade pbuilder
```

## What's in this repo

- `Casks/pbuilder.rb` — the Homebrew cask, auto-generated by GoReleaser on
  every release. Do not edit by hand.
- [Releases](https://github.com/Project-Builder-Schematics/homebrew-tap/releases)
  — pre-built binaries for macOS (arm64/amd64) and Linux (arm64/amd64) with
  checksums.
